# Ctrl-Alt-Boo-
🚀 Upskill Navigator

Your all-in-one personalized learning assistant — built to guide, motivate, and upskill users efficiently through smart AI tools and gamification.

🧠 Overview

Upskill Navigator helps learners plan, track, and enhance their skill development journey with AI-powered recommendations, multilingual support, and gamified progress tracking.

🧩 Features

Firebase Authentication — Secure email/password login.
AI Roadmap Generator — Personalized skill roadmap using AI guidance.
Survey Module — Captures user goals/interests for tailored recommendations.
Audio/Video Learning — Hands-on sessions with interactive timers.
Topic Summaries — Mindmaps and cheatsheets for quick revision.
Gamification — XP boosts, ranks, daily task calendar, and achievements.
Chatbot Assistant — Summarizes YouTube videos into notes or FAQs.
Multilingual Support — Learn in your preferred language.
Study Materials Dashboard — Centralized access to textbooks, notes, and resources.
Screen Time Tracker — Timer for focused study sessions.

⚙️ Tech Stack

Frontend: React + Tailwind CS
Backend: Firebase (Auth + Firestore + Storage)
AI Tools: OpenAI API / Gemini / Whisper for transcription
Hosting: Vercel or Firebase Hosting
Database: Firestore
